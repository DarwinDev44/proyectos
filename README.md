# 📈 Dashboard Colombia

Dashboard interactivo para la **visualización de datos públicos de Colombia**: mapas geográficos, gráficas dinámicas y procesamiento de datasets abiertos. Desarrollado en **JavaScript vanilla** con una arquitectura modular (procesamiento de datos, configuración de mapa, gráficos y controlador de UI separados).

## ✨ Características

- 🗺️ **Mapa geográfico** de Colombia con datos por región.
- 📊 **Gráficas dinámicas** (charts mejorados) que reaccionan a la selección.
- 🔄 **Procesamiento de datasets** públicos en el cliente.
- 🧩 **Arquitectura modular**: datos, mapa, gráficos y UI desacoplados.
- ⚡ Sin frameworks: JavaScript vanilla.

## 📁 Estructura

```
proyectos/
├── index.html            # Documento principal
├── styles.css            # Estilos
├── main.js               # Orquestación / arranque
├── datos-colombia.js     # Dataset de Colombia
├── data-processor.js     # Procesamiento y transformación de datos
├── map-config.js         # Configuración del mapa geográfico
├── enhanced-charts.js    # Gráficas dinámicas
└── ui-controller.js      # Controlador de interfaz y eventos
```
